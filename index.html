    Spørgsmål, vi ofte får

    Kan du ikke finde svaret, så skriv til os. Vi svarer inden for én arbejdsdag.

    Hvad koster en chatbot?

    En chatbot starter ved 6.900 kr. i opsætning og 595 kr. om måneden for drift og AI-forbrug. Med booking i kalenderen er prisen 12.900 kr. og 995 kr. om måneden.

    Hvor bliver vores data af?

    Vi laver en databehandleraftale med jer og holder data inden for EU, hvor det er muligt. I ejer selv jeres data og samtaler.

    Skal vi skifte vores systemer ud?

    Nej. Vi bygger oven på det, I allerede bruger, fx hjemmeside, kalender, Microsoft 365 eller Google.

    Hvad sker der, hvis chatbotten ikke kan svare?

    Så sender den spørgsmålet videre til jer med kundens kontaktoplysninger, så I kan svare personligt.

    Kan chatbotten tale flere sprog?

    Ja. Den kan svare på dansk, engelsk og andre sprog, så turister og udenlandske kunder også får svar.
